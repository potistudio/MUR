# MUR

> VJ MUR captivates underground crowds by deadpanning through chaotic, glitch-heavy visuals that defy all logic.

## Status

> [!WARNING]
> This project is **currently under heavy development**.  
> The latest progress of this project can be seen on the [master branch](https://github.com/potistudio/LetsHarness/tree/master).

## Development

### Requirements

- Rust 1.100.0 or later

### Build

#### 1. Clone the repository

```sh
git clone https://github.com/potistudio/MUR.git
cd MUR
```

#### 2. Build the application

```sh
cargo build --release
```
